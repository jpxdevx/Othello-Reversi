# User Guide: Othello Reversi

Welcome to Othello! This guide will help you set up the environment and start playing against the AI.

## Prerequisites
- **Python 3.8+**
- **pip** (python package manager)

## Installation
1. Clone the repository to your local machine.
2. Open your terminal in the project root folder.
3. Install the required libraries (specifically the Ursina Engine for the GUI):
   ```bash
   pip install -r requirements.txt
